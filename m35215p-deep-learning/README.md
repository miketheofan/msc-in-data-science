# Deep Learning

**Institution**: Athens University of Economics and Business (AUEB)

## Project: Image Classification

A two-part deep learning project exploring image classification across different architectures and domains.

### [Part 1: Fashion-MNIST & CIFAR-10](image-classification-project/Part_1/)
Classification using MLP and CNN architectures on Fashion-MNIST and CIFAR-10 datasets, comparing performance from simple feedforward networks to custom ResNets.

**Technologies**: Python, TensorFlow/Keras, NumPy, Matplotlib

### [Part 2: MURA X-Ray Classification](image-classification-project/Part_2/)
Binary classification of musculoskeletal X-ray images (normal vs abnormal) using custom CNNs and pre-trained models (DenseNet121) on the Stanford MURA dataset.

**Technologies**: Python, TensorFlow/Keras, Transfer Learning
