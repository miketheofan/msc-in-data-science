# Data Visualization Projects

A collection of data visualization and analysis projects developed as part of AUEB's Data Visualization course.

## Projects

### [Airline Data Analysis](airline-data/)
Flight data analysis focusing on MCO (Orlando) and MIA (Miami) airports from 1998-2008. Includes comprehensive exploratory data analysis, delay patterns investigation, and external data correlations.

### [PISA Competition](pisa-competition/)
Analysis of PISA 2018 educational assessment data with focus on Greece's performance compared to international standards.

## Structure

```
data-visualization/
├── airline-data/          # Flight data analysis project
│   ├── code/             # Jupyter notebooks
│   ├── data/             # Processed datasets
│   ├── visualizations/   # Generated plots and charts
│   ├── presentation.pdf  # Project presentation
│   └── report.pdf        # Detailed analysis report
│
└── pisa-competition/     # PISA data analysis project
    ├── code.ipynb        # Analysis notebook
    ├── plots/            # Generated visualizations
    └── presentation.pdf  # Project presentation
```

## Getting Started

Each project contains its own README with specific setup instructions and dependencies.

1. Navigate to the project directory
2. Follow the project-specific README instructions
3. Install required dependencies
4. Run the Jupyter notebooks

## Requirements

- Python 3.8+
- Jupyter Notebook/Lab
- See individual project READMEs for specific dependencies
