# Project 2: SNAP Network Analysis

**Status**: Completed (December 2025)

## Overview

Community detection and centrality analysis using SNAP (Stanford Network Analysis Platform).

**Part 1**: Euler path/circuit detection
**Part 2**: Community detection scalability analysis on Watts-Strogatz graphs

## Technologies

Python, SNAP, NetworkX, Pandas, Matplotlib

## Key Results

- Implemented graph theory algorithms (Euler paths/circuits)
- Compared Girvan-Newman vs Clauset-Newman-Moore scalability
- Analyzed centrality measures (PageRank, Betweenness, HITS)
- Generated performance visualizations

- `project2-1.py`, `project2-2.py` - Standalone implementations
