# Social Network Analysis

**Institution**: Athens University of Economics and Business (AUEB)

## Projects

### Project 1: Word Network Analysis
Analysis of word co-occurrence networks from Charles Dickens' "David Copperfield" - network metrics, community detection, and visualization.

**Technologies**: Python, NetworkX, Gephi, Pandas, Matplotlib

### Project 2: Community Detection & Centrality
Community detection algorithm comparison and centrality analysis using SNAP.

**Technologies**: Python, SNAP, Pandas, Matplotlib

### Project 3: Distributed Graph Processing
Label propagation algorithm implementation using Apache Giraph.

**Technologies**: Java, Apache Giraph, Hadoop
